# 用户指南

## 1. 第一次使用

1. 启动 `python web_app.py`。
2. 打开 `http://127.0.0.1:8765`。
3. 点击“扫码登录”，使用 B 站 App 扫码。
4. 在“路径设置”中配置：
   - 程序数据目录：保存历史记录、缓存和配置。改动后重启生效。
   - 默认下载目录：视频下载到哪里。
   - FFmpeg / FFprobe：高清音视频合并和抽帧需要。
   - Aria2：可选下载器；不稳定时程序会自动回退内置下载器。
   - Eagle 导出/缓存目录：封面、套图、弹幕缓存等中间文件。
   - 错误日志文件：下载失败详情保存位置。
5. 点击“环境诊断”的“运行”，先确认 FFmpeg、FFprobe、下载目录、Eagle API 和写入权限是否正常。

## 2. 同步收藏夹

1. 在左侧“数据源”选择收藏夹。
2. 点击“同步收藏夹”。
3. 中间列表会显示视频封面、标题、BV、时长和下载状态。
4. 可以用搜索、时长、月份柱状图、仅看未下载来筛选。

## 3. 下载视频

1. 勾选要下载的视频。
2. 确认右侧“下载”区域的保存目录、清晰度和限速。
3. 点击“启动下载”。
4. 下载完成后程序会写入下载记录，之后同一 BV 会显示为已下载。

## 4. 换设备不重复下载

旧设备：

1. 点击“导出记录”。
2. 保存生成的 `bili_history_*.json`。

新设备：

1. 点击“导入记录”。
2. 选择旧设备导出的 JSON。
3. 同步收藏夹后，已下载过的视频会被标记出来。

## 5. Eagle 导入视频

1. 打开 Eagle。
2. 在 BiliDownloader 右侧 Eagle 区域选择 `.library` 目录。
3. 选择要导入的 Eagle 文件夹。
4. 选择速度模式：
   - 快速：更少帧，速度优先。
   - 平衡：推荐。
   - 高质量：更多候选帧，会更慢。
5. 点击“导入已下载视频到 Eagle”。
6. 如果勾选“导入后删除源视频”，成功导入后会删除下载目录中的原视频。
7. 右侧任务区会显示进度、成功数、失败数和最近错误。失败项目可以根据错误提示处理后重新执行。

## 6. 修复 Eagle 文件夹封面

用于处理已经在 Eagle 库里的本地视频。

1. 选择 Eagle 库和目标文件夹。
2. 默认会跳过已经有自定义封面的条目。
3. 如果要全部重做，勾选“强制刷新已生成封面”。
4. 点击“修复选中文件夹封面”。

匹配逻辑：

- 优先用 Eagle 条目中的 BV、URL、标签或备注。
- 再用历史下载记录、收藏夹缓存、旧 manifest 里的标题匹配。
- 如果能匹配到 BV，会使用 B 站封面和本地/缓存弹幕峰值。
- 如果匹配不到 BV，不再请求封面或弹幕，直接从本地视频抽帧生成套图。

## 7. 常见问题

### 下载后没有声音

通常是音视频分离流没有合并成功。请确认 FFmpeg 路径有效。

### 部分电脑 aria2 下载失败

程序会自动回退到 yt-dlp 内置下载器。也可以在“路径设置”里清空 Aria2 路径。

### Eagle 缩略图没马上变化

Eagle 可能缓存缩略图。切换文件夹、刷新 Eagle 或重启 Eagle 后再看。

### 不知道哪里配置错了

先运行“环境诊断”。如果出现“处理”或“建议”，按提示检查路径、Eagle 是否打开、`.library` 目录是否选对。诊断只检查本机环境，不会批量请求 B 站。

### B 站搜索返回 412

这是请求被限制或响应异常的表现。程序会优先使用本地缓存，避免频繁请求。不要短时间重复大批量搜索。
